# Factory Power Monitoring

Portrait Android sample dashboard for plant electrical monitoring.

Layout: Realtime Plant Usage, Usage Distribution, Source, a scrollable 16-feeder card, Load Trend, and Total Energy Usage.

The included GitHub Actions workflow builds a debug APK. Upload the contents of this folder to the repository root, then use Actions > Build Android APK > Run workflow.

Sample data only; intended as the UI foundation for later connection to real meters/PLC/Modbus/MQTT data.
